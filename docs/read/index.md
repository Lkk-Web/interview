# 前言

一本书要么帮你赚钱，要么帮你做更好的决策，要么帮你理解世界。

如果一本书读完以后，这三个问题都回答不了：

- 它能提升我的专业能力吗？
- 它能改善我的决策质量吗？
- 它能让我更理解人、商业或社会吗？

那它当前阶段的优先级就可以放低。

阅读可分类：

1. 软件架构（决定职业上限）
2. 商业与产品（决定能否创造价值）
3. 投资与经济（决定财富增长方式）
4. 管理与沟通（决定影响力）
5. 历史与传记（决定认知广度）

> 阅读总结的过程就是建立自己的知识体系。

1. 讲了什么？

2. 解决什么问题？

3. 我会怎么做？
